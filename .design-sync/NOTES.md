# design-sync notes — mbt-gym

- App-repo, geen library: geen `dist/`, converter draait in synth-entry mode vanaf `src/components` met `componentSrcMap`-pins. `tsconfig.json` nodig voor `@/`-aliassen.
- CSS: Tailwind v4 (`@tailwindcss/postcss` in de app). Voor de sync compileren we `src/app/globals.css` met de standalone `@tailwindcss/cli` (in `.ds-sync/node_modules`) naar `.design-sync/.cache/tailwind.css` (= `cfg.cssEntry`, en `cfg.buildCmd` regenereert hem). CLI draaien vanaf repo-root zodat source-detectie `src/**` scant.
- Satoshi laadt via remote Fontshare `@import` bovenin globals.css (zoals de app zelf) → verwacht `[FONT_REMOTE]`, geen actie.
- `src/components/layout/*` (Header, sidebars, bottom-navs) bewust uitgesloten: importeren allemaal `next/navigation` en crashen buiten de app. Kandidaat voor latere re-sync met router-shim.
- `ui/form.tsx` uitgesloten: react-hook-form-glue, geen visueel onderdeel.
- `dark-ui/index.tsx` is de eigen athletic-dark kit (1 bestand, ~40 exports). Niet-component exports: `P` (paletobject), `CATEGORY_COLORS`, `DARK_CHART_COLORS`, `DARK_CHART_STYLES`. Compound-subparts (DarkDialogTrigger e.d.) horen in de bundle maar krijgen geen eigen kaart.
- App is dark-first: dark-ui-componenten verwachten donkere achtergrond; previews waarschijnlijk wrappen in donkere container (`.dark`/`athletic-dark` context) — uitzoeken in de verify-loop.
- Repo is PUBLIC op GitHub: `.design-sync/` bevat geen PII en mag gecommit; nooit compliance/-inhoud in previews/voorbeelddata gebruiken (geen echte patiëntnamen — fictieve NL namen ok in previews? nee: gebruik generieke placeholders zoals "J. de Vries"-loze rollen, bv. "Atleet", "Sessie 3").
- `guidelinesGlob: []` bewust: default glob pakte `docs/clinical-tests-reference.md` + `docs/competitive-analysis-theprehabguys.md` — geen design-guidelines, horen niet in het design-project. Brand/stijl-context komt via `conventions.md` (readmeHeader).
- Entry is handgeschreven: `.design-sync/entry.tsx` (alleen gecureerde exports), meegeven als `--entry .design-sync/entry.tsx` bij elke build/resync. `next/link` geshimd naar `<a>` via `paths` in `.design-sync/tsconfig.sync.json` (+ exact-match mapping voor `@/components/dark-ui` omdat esbuild de directory-mapping niet naar index.tsx resolvet).
- Satoshi wordt geshipt via `cfg.extraFonts` → `.design-sync/fonts/satoshi/` (woff2 400/500/700 + satoshi.css, gefetcht van Fontshare CDN). Map is GEGITIGNORED: Fontshare-licentie staat publieke redistributie van fontbestanden niet toe en de repo is public. Op een verse clone: her-fetch met het node-script in de sync-geschiedenis of via `curl 'https://api.fontshare.com/v2/css?f[]=satoshi@700,500,400'` (browser-UA meesturen voor woff2-URLs). De remote Fontshare `@import` blijft óók in de gecompileerde CSS staan (app-pariteit); lokaal @font-face is de fallback als het design-render-env remote hosts blokkeert.

## Known render warns
- `[FONT_MISSING] "Cascadia Code", "Source Code Pro"` — fallback-namen uit Tailwind v4's default `--font-mono`-stack; de app shipt ze ook niet en valt door naar Menlo (brand-mono is bewust Menlo-first via `--font-mono-athletic`). Geen actie.
- GEEN `cfg.provider` gebruiken: een globale wrapper maakt de preview-root nooit-leeg waardoor de floor-card-detectie kapot gaat (alles wordt "blank" i.p.v. nette typografische kaart). In plaats daarvan: `DsThemeRoot` (`.design-sync/shims/ds-provider.tsx`, via `extraEntries` in de bundle) en elke AUTHORED preview wrapt zijn eigen content in `<DsThemeRoot>`. Zelfde component is ook de wrap-instructie voor de design-agent in conventions.md.
